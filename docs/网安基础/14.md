## 网络扫描 网络发现 端口扫描 主机发现
网络扫描分类：**主机扫描、端口扫描、操作系统识别、漏洞识别**

!!! Warning "Tips"
    网络扫描还包含后续的操作系统识别和漏洞识别操作。

### 端口扫描 :pear:【重要】
端口扫描用于探测目标主机上开放了哪些服务。

- **UDP 扫描**：监听中的端口不会回应，关闭的端口会回复 `ICMP_PORT_UNREACH`。
- **TCP 扫描**：

    1.  **全连接扫描**：完成完整的 TCP 三次握手。

    2.  **TCP SYN 扫描**：若收到 `SYN+ACK` 则发送 `RST` 终止连接，避免被日志记录；若收到 `RST` 则说明端口关闭。

    3.  **FIN 扫描**：发送 FIN 包，收到 `RST` 说明端口关闭，无回复说明端口开放。

    4.  **TCP NULL & TCP Xmas 扫描**：

        - NULL：所有 TCP 标志位为 0
        - Xmas：`FIN`/`URG`/`PUSH` 标志位为 1
        - 收到 `RST` 说明端口关闭，无回复说明端口开放。

- **FTP 扫描**：使用 `PORT`/`LIST` 命令。

!!! Warning "Tips"

    - 端口扫描可记为 **U-T-F**（UDP、TCP、FTP）。
    - FTP 的 `PORT`/`LIST` 命令均发往 **21 端口**：`PORT` 告知服务器通过 **20 端口** 向客户端指定端口传输数据，`LIST` 用于查询文件列表。

### 主机发现 :pear:【重要】
主机发现用于探测目标主机的工作状态，判断其是否在线。

- **基于 ICMP**：发送 `ICMP ECHO` `ping` 或地址掩码请求，但防火墙常对 ICMP 查询进行过滤。
- **基于 IP**：发送异常 IP 数据包，诱使目标回复“分片重组超时”、“参数有问题”等 ICMP 差错报告报文。
- 原理：向目标 IP 发送特定探测报文，根据是否收到回复判断主机在线状态，利用 ICMP、TCP、ARP、UDP 等协议的响应机制。

### 操作系统识别
判断目标主机的操作系统类型。

### 漏洞扫描
判断目标主机可能存在的安全漏洞。

### 隐匿性策略

- 减缓扫描速度
- 数据包字段随机化
- 使用虚假源地址
- 采用分布式扫描
