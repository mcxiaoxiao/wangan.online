# 文档目录

本目录用于存放各类学习资料和文档文件。

## 目录结构

- `samples/` - 示例文档
- `subjects/` - 按科目分类的资料
  - `network-security/` - 网络安全
  - `information-security/` - 信息安全基础
  - `cryptography/` - 密码学

## 使用说明

1. 将您的 DOC/DOCX 文件放入相应的目录中
2. 文件会自动在网站上显示，可以在线查看
3. 建议使用有意义的文件名，便于查找和管理

## 文件命名规范

建议使用以下格式：
- `科目名_章节名_内容描述.docx`
- 例如：`网络安全_第一章_基础概念.docx`
