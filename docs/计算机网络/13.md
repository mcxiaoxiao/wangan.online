## BGP（边界网关协议）路径向量路由算法 :pear:【重要】

### 核心报文类型

BGP 包含四种报文：

- **OPEN**：建立 BGP 会话
- **UPDATE**：核心报文，用于发布/撤销路由信息
- **KEEPALIVE**：维持 BGP 连接，周期性发送
- **NOTIFICATION**：通知错误信息，用于关闭会话

### BGP 路由信息格式
BGP 路由 = **前缀 + AS-path + next-path**

- **前缀**：目的网络地址（如 `203.0.113.0/24`）
- **AS-path**：途经的自治系统路径（如 `65001 65002 65003`），防止路由环路
- **next-path**：逻辑路径向量，包含完整 AS 路径和目的前缀
- **next-hop**：本路由器发往目的网络的下一跳 IP 地址（通常是本地 IGP 可解析的边界路由器地址）

### 热土豆（烫手山芋）选路算法

- **核心思想**：尽快让分组离开本 AS，因此**经过本地的路由器越少越好**，由内部网关协议（IGP）执行
- **Next-Hop 比较**：BGP 优选去往 `Next-Hop` IP 地址的 **IGP 开销最小** 的路由

### 工作原理

1.  每个 AS 管理员至少选择**一个边界路由器作为 BGP 发言人**
2.  BGP 发言人之间通过 **TCP 连接** 建立 **BGP 会话**，交换可达性信息
3.  利用 BGP 会话同步网络可达性信息，最终得到到达各 AS 的较好路由
4.  AS 之间路由选择由**策略**主导

### 选路流程

优先级从高到低：

1.  **本地偏好值**：最高优先级，由管理员配置
2.  **最短 AS-PATH**：选择途经自治系统最少的路由
3.  **热土豆选路**：选择最靠近 `Next-Hop` 路由器的路由（IGP 开销最小）
4.  **BGP 标识**：若仍有多个路由，选择 BGP 标识最小的路由

---

!!! Warning "Tips"
    热土豆算法也叫“烫手山芋算法”，形象表达了尽快将分组转发出本 AS 的核心思想。
    示例：
    - Prefix: `203.0.113.0/24`（目的网段）
    - AS-Path: `65001 65002 65003`（途经 AS 列表）
    - Next-Hop: `198.51.100.17`（本路由器的下一跳 IP）
