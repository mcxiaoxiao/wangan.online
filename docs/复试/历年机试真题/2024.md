## 四、编程题

### 编程1：结构体排序
```c
struct Res{
    int id;
    char name[10];
    int accessCount;
};
```
要求：
1. 定义结构体数组 Resources
2. 输入n，再输入n组 id、name、accessCount
3. 按 accessCount **从大到小**排序
4. 输出 id、name、accessCount

### 编程2：飞船航行总距离
规则：
第1年：0.01 光年
第2年：0.03 光年
第k年（k≥3）：距离 = 前两年之和
输入n，输出n年总航行距离。
若n不合法，输出 error。

### 编程3：字符串逆置拼接
输入字符串a（长度≤10）
1. 将a逆置得到b
2. 将b拼接在a后面
3. 输出最终串
要求数组开足空间，处理结束符。

### 编程4：满足条件的绳子长度
输入n，输出**≤n**且满足以下所有条件的数：
1. 是素数
2. 模4余1
3. 模5余1
4. 模7余3
5. 模9余4
