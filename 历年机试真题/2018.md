## C语言程序设计
### 1. 畅销商品统计（25分）
**题目描述**：
有10种商品，编号为1-10。现有 $n$ 个顾客前来购买，每个顾客只买一种商品。如果某种商品的销量大于 $m$，则标记为**畅销商品**。
编写一个程序，实现从小到大输出所有**畅销商品的编号**。

**输入格式**：
- 第一行输入两个正整数 $n$ 和 $m$（$1 \le n \le 1000$，$1 \le m \le n$）。
- 第二行输入 $n$ 个整数（取值范围1-10），代表每个顾客购买的商品编号。

**输出格式**：
- 按照**从小到大**的顺序，输出所有畅销商品的编号。
- 多个编号用空格隔开，行尾无多余空格。

**限制条件**：
1. 禁止使用指针、结构体、共用体、文件、`goto`、枚举类型。
2. 使用标准C语言编程，所有变量必须在第一条可执行语句之前定义。

**示例**：
```text
输入：
10 2
1 2 2 3 3 3 4 5 10 10

输出：
2 3 10
```
*(解释：商品2销量2、商品3销量3、商品10销量2，均大于m=2，按升序输出)*

### 2. 字符串循环移位（25分）
**题目描述**：
输入一个字符串（长度$\le 80$）和一个整数 $k$，将字符串**循环向右移动 $k$ 个位置**。
- 例如：字符串 `"abcde"` 向右移动 2 位，结果为 `"deabc"`。
- 要求移动过程中不使用额外的数组空间（除临时变量外），在原字符串上直接操作。

**输入格式**：
- 第一行输入整数 $k$。
- 第二行输入字符串。

**输出格式**：
- 输出移位后的字符串。

**限制条件**：
1. 禁止使用指针操作（如`char *p`），只能使用数组下标。
2. 禁止直接调用现成的库函数实现移位，需手动实现算法。
3. 标准C语言编程，变量先定义。

### 3. 程序改错题（20分）
#### 题目一：求数组最大值及其下标
**功能描述**：
输入一个 $3 \times 3$ 的二维整数数组，找出其中的最大值，并输出该最大值及其所在的**行号和列号**（从0开始计数）。
**下方代码存在隐蔽错误，请修正**：
```c
#include <stdio.h>

int main() {
    int a[3][3];
    int i, j, max, row=0, col=0;
    
    // 输入数组
    for(i=0; i<3; i++); {
        for(j=0; j<3; j++) {
            scanf("%d", &a[i][j]);
        }
    }
    
    // 初始化最大值
    max = a[0][0];
    
    // 查找最大值
    for(i=0; i<3; i++) {
        for(j=0; j<3; j++) {
            if(a[i][j] > max) {
                max = a[i][j];
                row = i;
                col = j;
            }
        }
    }
    
    printf("max = %d, row = %d, col = %d\n", max, row, col);
    return 0;
}
```

#### 题目二：素数判断函数
**功能描述**：
输入一个整数 $n$，判断其是否为素数。如果是素数输出 `"Yes"`，否则输出 `"No"`。
**下方代码存在隐蔽错误，请修正**：
```c
#include <stdio.h>
#include <math.h>

int isPrime(int n) {
    int i;
    if (n <= 1) return 0;
    for (i=2; i<sqrt(n); i++) {
        if (n % i == 0) {
            return 0;
        }
    }
    return 1;
}

int main() {
    int n;
    scanf("%d", n);
    if (isPrime(n)) {
        printf("Yes\n");
    } else {
        printf("No\n");
    }
    return 0;
}
```
