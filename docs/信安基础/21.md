## 传统病毒、蠕虫、木马的结构原理 隐藏技术 API 劫持 CIH 尼姆达 Nimda Redcode 端口复用 反弹端口 :blue_circle:【重要】

### 发起者角度网络威胁分类
- 主动攻击：网络监听、黑客攻击
- 被动攻击：用户通过某种途径被动感染木马、病毒

### 攻击手段网络威胁分类
病毒（病毒、蠕虫、木马）、网络入侵（黑客攻击、DDoS、口令攻击、嗅探攻击）、欺骗类威胁（间谍软件、钓鱼）

---

### 传统病毒（eg. CIH） :blue_circle:【重要】
三个模块：**启动模块，传染模块，破坏模块**。

当系统执行了感染病毒的文件时，病毒的**启动模块**开始**驻留在系统内存**中。**传染模块和破坏模块**的发作均为**条件触发**，当满足了条件，病毒开始传染别的文件或破坏系统。

CIH 驻留在 windows 核心内存里，只要运行了 **PE 格式的 exe 文件**就会感染上该病毒。

---

### 蠕虫病毒（eg. Nimda Redcode） :blue_circle:【重要】
主体：**驻留模块，传播模块**。

不需要寄生在宿主文件中，传播途径**以计算机为载体，以网络为攻击对象**，利用漏洞。

尼姆达也会感染本地 **PE 格式的 exe**，执行 exe 时会发作。

---

### 木马（eg. 灰鸽子） :blue_circle:【重要】
是有：**隐藏性的，传播性的**，可被用来**进行恶意行为**的**程序**。一般**不直接**对计算机**产生危害**，**被动（手动）植入**，主要**以控制计算机为目的**。

- 主要传播：电邮挂马、网页捆绑木马应用程序
- 被动植入：手动植入（一般如此）
- 主动植入：通过程序自动安装

!!! Warning "Tips"
    蠕虫一般是溢出漏洞等更自动的方法传播的，没有木马那么明显。这三个里面只有病毒是明确用来破坏主机的，木马以控制计算机为目的，蠕虫视网络为攻击对象。

#### 木马三部分组成
- **控制端程序（客户端）**：黑客用来控制远程计算机的木马程序
- **木马程序（服务器端）**：是木马的**核心**，是潜入被感染的计算机内部，获取其操作权限的程序
- **木马配置程序**：**配置**名称图标伪装隐藏木马程序，**配置**反馈信息传输**路径**

---

### 隐藏技术
- **隐藏文件**：拦截 API 函数**调用**，隐藏文件和注册的服务
- **隐藏进程**：**修改** API 函数**入口地址**，使别的程序在调用时**转向木马程序**并过滤掉自己的进程信息
- **隐藏通信**：**端口复用**（绑定到正常端口）/ **反弹端口**（主动连接，比如 80 端口连接）
