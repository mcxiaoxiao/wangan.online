!!! info "阅读提示"
    由于信息安全与网络安全两部分知识点存在交叉，本知识库将重复内容优先整合至信息安全部分。例如，考纲中的“身份认证技术”已在信安部分详细讲解，此处便不再重复。

## 考试要求
掌握网络安全领域中由于各层网络协议缺陷及其引发的网络攻击、软件程序缺陷及其引发的攻击、资源占用攻击等；掌握网络监听技术及相关网络数据获取的软件开发能力；掌握入侵检测的相关理论和技术以及典型的模式匹配方法和分类方法；掌握身份认证相关的模型、技术和系统。


主要用书：

- 吴礼发，洪征，李华波编著，网络攻防原理与技术，机械工业出版社，2017.01
- 薛静锋，祝烈煌主编，入侵检测技术（第2版），中国工信出版集团 人民邮电出版社，2016.01

## 学习建议
这门课资料最少，课本还很厚，建议按着思维导图、考纲的内容、真题考点挑这两本厚厚的书里面的部分章节的部分内容学，《入侵检测技术》这本书比较没用。相比于实际考察范围来说课本内容相当冗余，大家需要根据[思维导图](https://github.com/mcxiaoxiao/wangan.online/tree/HIT837-Book-of-Answer/%E6%80%9D%E7%BB%B4%E5%AF%BC%E5%9B%BE)和考到过内容，把课本里面的对应章节的对应内容学扎实。算法部分比较杂（Kmeans、密度聚类、DBSCAN、决策树、层次聚类、朴素贝叶斯、AC、WM、BM、KMP），且课本在算法部分没啥用，需要自己看[对应PPT和相关材料](https://github.com/mcxiaoxiao/wangan.online/tree/HIT837-Book-of-Answer/%E7%AE%97%E6%B3%95)去补充。网安可能是三门里最让人不知道从何下手的一门，不过网上的相关资料很充分，实际出题并不难，所以从备考意义上来说这可能也是最简单的一门。近几年网安考纲变动频繁，大家需要关注当年考纲与过往对比，近年新增部分考到概率会更大，习题建议完成：

- [历年真题](/真题/)
- 《网络攻防原理与技术》与考纲有关章节的[课后题](https://github.com/mcxiaoxiao/wangan.online/blob/HIT837-Book-of-Answer/%E4%B9%A0%E9%A2%98/%E3%80%8A%E7%BD%91%E7%BB%9C%E6%94%BB%E9%98%B2%E5%8E%9F%E7%90%86%E4%B8%8E%E6%8A%80%E6%9C%AF%E3%80%8B%EF%BC%88%E7%AC%AC3%E7%89%88%EF%BC%89%E8%AF%BE%E5%90%8E%E4%B9%A0%E9%A2%98%E5%8F%82%E8%80%83%E7%AD%94%E6%A1%88.pdf)，这本书的习题质量挺高

信安与网安不像计算机网络那样资料充足，其中网安最不充足，但好在知识点部分相对计网和信安更容易理解和记忆，基本上过一轮就差不多能明白，且观察真题会发现其中很多题目和信安重合，如果已经学完信安，网安的推进速度会很快。其难点和重点主要是一堆算法（网安计算题分数≈信安+计网计算题分数）。建议后期保证 3 小时以上的复习时间，结合教材、思维导图和手册资料，重点吃透手册中标注的核心考点和真题。如果感觉复习没底，就把考纲和历年真题拿出来，和自己当前掌握的内容做对比，只凭思维导图在脑中梳理一遍知识框架，遇到卡壳的地方再回头翻书或对照手册补全，很快就能明确下一阶段的复习重点。另外，信安、网安的练习题相对较少，可以把考点和参考资料交给大模型，让它针对性出题练习，弥补了题量不足的问题。
