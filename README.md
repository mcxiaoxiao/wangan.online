## 🌐 在线文档查看器

本项目提供一个基于 GitHub Pages 的在线文档查看器，支持：

### ✨ 功能特性

- **📤 文档上传**: 支持 DOC/DOCX 格式文件的在线上传
- **👁️ 在线预览**: 无需下载即可在浏览器中查看文档内容
- **📱 响应式设计**: 支持桌面和移动设备访问
- **💾 本地存储**: 上传的文档保存在浏览器本地存储中
- **📋 预置资料**: 提供预先准备的学习资料和样例文档
- **🎨 现代界面**: 美观的用户界面，提供良好的用户体验

### 🚀 使用方法

1. **访问网站**: 打开 [GitHub Pages 链接](https://mcxiaoxiao.github.io/HIT837-Book-of-Answer/)
2. **上传文档**: 点击"选择 DOC/DOCX 文件"或直接拖放文件到上传区域
3. **查看文档**: 点击文档列表中的"查看"按钮即可在线预览
4. **浏览预置资料**: 查看已准备好的学习资料和参考文档

### 📂 目录结构

```
├── index.html          # 主页面
├── docs-handler.js     # 文档处理脚本
├── _config.yml         # GitHub Pages 配置
├── docs/               # 文档存储目录
│   ├── samples/        # 示例文档
│   └── subjects/       # 按科目分类的资料
│       ├── network-security/     # 网络安全
│       ├── information-security/ # 信息安全基础
│       └── cryptography/         # 密码学
└── README.md
```

### 🛠️ 技术实现

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **文档转换**: Mammoth.js (DOC/DOCX 转 HTML)
- **托管平台**: GitHub Pages
- **响应式框架**: 自定义 CSS Grid/Flexbox

### 📝 支持的文件格式

- ✅ Microsoft Word (.doc, .docx)
- ✅ Markdown (.md) - 预置文档支持
- 🔄 更多格式支持正在开发中...

### 🔒 隐私说明

- 上传的文档仅保存在您的浏览器本地存储中
- 不会上传到任何服务器或第三方服务
- 清除浏览器数据会删除已上传的文档
