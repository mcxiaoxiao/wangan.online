## 子网划分 CIDR 子网掩码

**CIDR** = `IP/前缀长度`（如 `192.168.1.0/24`），打破 A/B/C 类地址限制。

**子网掩码** = 连续 `1`（网络位） + 连续 `0`（主机位）。

| CIDR  | 子网掩码         | 一个子网内可用 IP 范围 | 可用数量 |
|-------|------------------|------------------------|----------|
| `/24` | `255.255.255.0`  | `1 - 254`              | `254`    |
| `/25` | `255.255.255.128`| `1 - 126`              | `126`    |
| `/26` | `255.255.255.192`| `1 - 62`               | `62`     |
| `/27` | `255.255.255.224`| `1 - 30`               | `30`     |
| `/28` | `255.255.255.240`| `1 - 14`               | `14`     |

!!! Warning "Tips"
    可以画哈夫曼树划分。
