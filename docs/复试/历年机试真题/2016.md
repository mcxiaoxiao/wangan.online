## 二、普通编程题（60分）
### 1. 整数位数与数字统计（30分）
- 功能：输入int整数，判断位数，统计0-9每个数字出现次数
- 限制：禁止指针、结构体、共用体、文件、goto、枚举；标准C，变量先定义
- 输入提示：`Please enter the number:\n`
- 输出格式：`%d: %d bits`，逐行输出数字与个数

### 2. 用户密码设置模拟（30分）
- 功能：设置8位密码，两次输入一致则成功，否则失败
- 函数原型：`int Setting(char password[])`
- 限制：同上
- 输入提示：
  - `Please input password with 8 characters:\n`
  - `Please input again:\n`
- 输出：
  - `Successfully set password:%s\n`
  - `Failure!\n`
