## 数据链路层编程接口 Libpcap winpcap 数据采集【重要】
`libpcap` 和 `winpcap` 都是**数据链路层**编程接口，使用时需先设置**混杂模式**，并可通过 **BPF 语法**编译与设置过滤器，对数据包进行过滤。

### 核心 API 与参数作用

- **`pcap_lookupdev()`**：查找网卡，用于发现可用的网卡。
- **`pcap_lookupnet()`**：获取网卡参数，得到指定网卡的 **IP 地址** 和 **子网掩码**。
- **`pcap_open_live()`**：打开网卡，参数包括：
    - `snaplen`：指定捕获的最大字节数
    - `promisc`：设置网络接口是否进入**混杂模式**（promiscuous mode），取值 `true`/`false`
- **`pcap_datalink()`**：返回链路层类型，如以太网（Ethernet）、IEEE 802.11（无线）等。
- **`pcap_compile()`**：编译过滤策略，将字符串形式的过滤规则编译成内核可执行的过滤程序。
- **`pcap_setfilter()`**：指定过滤程序，将编译好的过滤策略应用到对应网卡。
- **`pcap_open_offline()`**：打开存盘文件，准备读取离线数据包。
- **`pcap_dump_open()`**：打开存盘文件，准备写入捕获的数据包。
- **`pcap_dump()`**：将分组输出到之前打开的存盘文件中。
- **`pcap_dispatch()`**：处理最多 `cnt` 个数据包：
    - `cnt=0`：处理所有数据包
    - `cnt=-1`：一次读取一个缓冲区的数据包（可能少于 `cnt`），直到错误、EOF 或超时
- **`pcap_loop()`**：连续捕获 `cnt` 个数据包，处理完成或出错后退出：
    - 超时不返回
    - `cnt<0`：持续循环抓包，直到出现错误
- **`pcap_next()`**：获取 **1 个数据包** 后立即返回，并将数据包存放在返回值指向的内存中。
