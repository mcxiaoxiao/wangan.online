## 网络监听的检测
- **Ping 可疑主机的 IP，使用错误 MAC**：若主机仍响应，说明其网卡处于混杂模式，正在监听。
- **发送垃圾数据包**：对比攻击前后主机的响应速度，若明显变慢，可能存在监听。
- **广播 ARP 数据包查询不存在的 IP**：若收到回复且回复方将自身 MAC 作为解析结果，说明该主机正在进行 ARP 欺骗。
- **对不存在的 IP 发送 Ping 包**：若有主机对这些不存在的 IP 执行 **DNS 反向查询（rDNS）**，则说明该主机正在监听网络流量。

!!! Warning "Tips"
    - 交换网络环境中，网络监听通常意味着存在 **ARP 欺骗**。
    - **rDNS（反向 DNS）**：将 IP 地址解析为域名的查询方式，使用 **PTR 记录** 实现 IP 到域名的映射，常用于验证邮件服务器身份，防止垃圾邮件。例如，邮件服务器收到邮件时，会查询发件人 IP 的反向 DNS，确认其是否来自声称的域名。
