## SET 与 SSL 比较

| 对比维度 | SSL | SET |
|----------|-----|-----|
| **多方认证与信息隔离** | 不能实现多方认证和信息隔离 | 支持多方认证，实现信息隔离 |
| **安全与功能范围** | 主要针对传输层安全 | 不止对传输做规范，在**商务性、服务性、集成性、协调性**上安全性更高 |
| **应用场景** | 主要和 WEB 一起工作 | 为信用卡多方交易设计 |
| **应用代价** | 低 | 远大于 SSL |

### 核心差异总结
- **SSL**：侧重端到端传输安全，实现简单，适合 Web 场景，但无法满足复杂电子支付的多方信任与信息隔离需求。
- **SET**：面向信用卡支付的完整安全协议，在商务流程、多方信任、信息隔离等方面更完善，但实现复杂、部署代价高。
