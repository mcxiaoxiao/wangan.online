## 三、普通编程题

### 1. 猴子吃桃问题（15分）
- 描述：第10天剩1个，每天吃前一天一半多1个，求第一天摘桃数
- 要求：`%d\n`输出；禁止递归、链表、指针、结构体、goto、共用体、文件、类；纯C，变量先定义

### 2. 反馈意见中位数（15分）
- 描述：数组存≤20个1-10反馈，计算中位数（偶数取中间两数平均）
- 要求：
  1. 输入提示：`Input total number of feedbacks`
  2. 输入提示：`Input feedbacks`
  3. 函数`int Median(int answer[],int n)`
  4. 输出：`Median value=%d\n`
  5. 选择排序从大到小，函数`void DataSort(int a[],int n)`

### 3. 国名字典序排序（20分）
- 描述：10个国名，含空格，字典序排序输出
- 要求：
  1. 输入10国名
  2. 支持含空格
  3. 交换排序（冒泡），函数`void SortString(char str[][MAX_LEN],int n)`
  4. 输出提示：`Sorted results`，一行一个
