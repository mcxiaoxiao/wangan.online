## **💬 面试详解 (流水线，下午)**

**🔄 1. 基本流程**

*   **形式**：四个独立考核环节，考生4人一组，像流水线一样依次轮转完成。
*   **考场**：通常在一个大教室的四个角落设置四个面试点，每个点由两位老师负责。
*   **流程**：一次进去四个同学，各自去教室的四个角落，每五分钟，顺时针换个环节。
*   **准备**：什么都不用准备，就空手进就行（也就是说不用带简历等材料，没有中英文自我介绍，**不让透露姓名学校**）。
*   **管理**：复试完全匿名，哪个环节先开始随机。

**🎯 2. 四个面试环节 (每环节约5分钟)**

| 环节顺序 | 考察内容 | 备考提示 |
| :--- | :--- | :--- |
| **第一环节** | **沟通能力** | **内容**：<br>1. 个人基本情况，专业，是不是党员<br>2. 对报考院系的了解（如：列举哈工大计算机相关专业）。<br>3. 思想政治与日常表现（如：党员的义务与实践）。<br>4. 未来职业规划（是否读博、留校、研究方向等）。 |
| **第二环节** | **科创与实践能力** | **内容**：<br>1. **首选**：深入询问竞赛、项目经历，考察创新与实践能力。<br>2. **若无突出科创实践经历**则**重点围绕毕设** 展开深度提问，包括选题背景、技术方案、个人贡献等。<br>**提示**：务必对自己的毕设、论文、专利、项目经历烂熟于心，能清晰阐述技术细节和思考过程。 |
| **第三环节** | **综合运用能力** | **形式**：**现场抽题（七选一）**，抽中后需先朗读题目再作答。<br>**示例**：涉及“智慧系统”等领域的开放性、综合性问题 |
| **第四环节** | **问题求解** | **形式**：**现场抽题（四选一）**，通常为系统设计或问题求解类题目。<br>**示例**：“设计一个远程监考系统”。可能追问：<br>① 系统需要哪些核心模块？<br>② 如何保证系统的高可用性（稳定性）？<br>③ 如何提升系统的智能性？<br>**提示**：网安专业仅在第四环节可能与其它专业不同，会侧重837&网安相关知识点的运用。|

**面试注意事项**：

- 一定要能与老师们聊起来，有东西说

- 老师们也很辛苦，给的分数大家都差不多，不用太担心

- 重点展示自己的专业能力和科研潜力

## **✍️ 机试详解 (全部上机，上午)**

**💻 机试内容**

*   **时间**：约2小时。
*   **形式**：在线答题平台，分AB卷，时间到系统自动提交。
*   **考试科目**：C语言、数据库、集合论与图论、数理逻辑、近世代数、算法设计
*   **题型与结构**： 机试大约包括 单选题（30道，约60分）、多选题（10道，约20分）、填空题（2道，出自离散和逻辑，约10分）、编程题（2-4道,每题15分，约30分）、程序改错题（1-3道，每题10分，约20分）

**机试注意事项**：

- 英语翻译部分已取消（2025年起）
- 重点关注数据库和C语言，这是分数的基础
- C语言改错题难度较大，做不出来问题不大，很多人得0分，保持平常心


**📚 教材建议**

- C语言：苏小红教授的《C语言程序设计学习指导》和《C语言程序设计》（实体书可用于登录SSE网站，《C语言程序设计学习指导》包含改错题，购买上面提到的附加资料或是只参考本仓库的C语言题目对于科班学生来说已经足够了，不是非得刷SSE，题目难度不会超过Leetcode中档题）

- 离散数学：棕色封面的屈婉玲版《离散数学》（如果不追求高分其实也可以不看，题目数量远不如数据库，且基础题占比大）

- 数据库：**无需准备教材**（通过MOOC和习题即可）

> 注：Z-library，Anna's Archive 等可以找到以上教材的电子版。

**💾 1. 数据库系统 (绝对核心，选择题占比近半数，约50分)**

*   **定位**：**唯一能通过扎实复习确保几乎满分**的科目，是笔试成绩的压舱石，有点像政治选择题的背法，要争取做到差不多能背答案的程度。
*   **参考课程**：中国大学MOOC - 哈工大 **战德臣** 教授《数据库系统（上/中/下）》，重要性 上≈下>中。
*   **复习材料**：**MOOC课后所有习题**（主要题源），仓库里的md笔记。
*   **方法**：
    必须完整学习课程，不一定要看视频，但是课后习题反复刷，直至**每题都掌握**。
    近年虽出现**少量新题**，但**主体**仍是**原题**或变式，在背熟原题答案的基础上，加深对原理的理解。
    优先级：**下篇 ≈ 上篇 > 中篇（内容抽象）**。
- [哈工大战德臣数据库系统（上）MOOC课程+习题](https://www.icourse163.org/course/HIT-1001516002?tid=1470930448)
- [哈工大战德臣数据库系统（中）MOOC课程+习题](https://www.icourse163.org/learn/HIT-1001554030?tid=1470918446)
- [哈工大战德臣数据库系统（下）MOOC课程+习题](https://www.icourse163.org/learn/HIT-1001578001?tid=1470929443)


**⚙️ 2. C语言 (编程与改错，实操性强，编程和改错题，总分的1/3，约50分)**

*   **定位**：通过1-4道编程和1-4道改错题集中考察，分值高（40-60分）。
*   **参考资源**：哈工大 **苏小红** 教授教材及配套MOOC（题目多为原题或改编），大可不看书不看课只看仓库里的材料，SSE（中、难题）或者苏小红版C语言程序设计学习指导题目（改错题、编程题）
*   **题型分析**：
    *   **编程题**：相对基础，常考**链表**操作，熟练用指针和结构体。需在codeblock中编写、debug。编程题难度与SSE相当，采用动态评分，仅通过部分测试点有时也可以获得15分以上。
    *   **改错题**：**难度较大**，综合考察语法和算法逻辑。**一处错即可能导致零分**。考试中多为逻辑错误，与SSE的语法错误不同，且每题必须全部改对才能得分。
*   **关键技巧**：
    *   **自测意识**：除了题目给的测试用例，必须**自行构造边界值、溢出值、特殊值进行测试**，确保代码稳健性。
    *   **编程题评分原理**（个人猜测）：哈工大复试是自动判分 + 语义保底的混合机制。沙箱编译运行 → 逐个测试点执行 → 比对测试点结果给分 或 代码语义分析保底（触发条件：所有测试点均未通过，评估AST、控制流、变量、函数结构等）。

-   [哈工大-SSE](https://sse.hit.edu.cn/train/#/main/home)

## **⏰ 备考过程建议**

**时间安排**

- **1月-2月**：初试后好好休息，适当放松，不要过于紧张，数据库、C语言、集合论与图论可以考虑过一轮
- **3月开始**：全力备考，建议每天学习5小时以上，开始做历年真题
- **备考周期**：以2025年3月29日复试为例，即使3月份开始全力学习一个月完全足够

**复习优先级**

1. **数据库**：优先复习，争取满分（基本盘）
2. **C语言**：重点复习，确保基础题得分（重点）
3. **集合论与图论**：需花时间正儿八经学，确保基础题得分（重点）
4. **算法设计**：难题不会，会题不难。对非跨考学生比较友好，可以速通王宏志课程（速通）
5. **数理逻辑**：相对简单，适当学（速通）
6. **逻辑题**：看往年真题即可，也可以补充一些面试常见逻辑题（速通）
7. **近世代数**：难度较大，可以记最基本定义（摆烂）

 **总体建议**

*   数据库、C语言、集合论与图论这三部分掌握得好机试就不会被拉分了
*   其他几门根据自己情况学，建议优先选择数理逻辑，懒得学近世代数就不学
*   私以为不用看任何视频课直接看文字资料即可，并且可以做到全程无纸化备考，看自己需求和习惯
*   题型分布每年都不一定一样，看运气，但还是建议多做往年真题
*   **蒙题终极口诀**：三长一短选最短，三短一长选最长，乱一点选 B，乱得很极端选 D，全都一样选 C。
*   **毕业设计**：没有足够科研经历的同学争取在复试前完成大部分工作，为后续复习腾出时间
*   **项目准备**：如果有项目经历，务必熟悉每个细节；如果没有，好好准备毕设，为复试服务
