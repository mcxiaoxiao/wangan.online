# HIT837 网络与信息安全基础

## 第一章 网络安全概述

### 1.1 基本概念

网络安全是指网络系统的硬件、软件及其系统中的数据受到保护，不因偶然的或者恶意的原因而遭受到破坏、更改、泄露，系统连续可靠正常地运行，网络服务不中断。

### 1.2 网络安全的目标

网络安全的目标主要包括：

1. **机密性（Confidentiality）**
   - 信息不被未授权的个人、实体或过程获取或泄露
   - 确保只有授权用户才能访问相应的信息资源

2. **完整性（Integrity）**
   - 保护信息不被未授权的修改
   - 确保信息在传输和存储过程中不被篡改

3. **可用性（Availability）**
   - 确保授权用户在需要时能够访问信息和相关资源
   - 系统能够及时、可靠地提供服务

### 1.3 网络安全威胁

常见的网络安全威胁包括：

- **恶意软件攻击**
  - 病毒、蠕虫、木马程序
  - 勒索软件、间谍软件

- **网络攻击**
  - DDoS攻击
  - 中间人攻击
  - SQL注入攻击

- **社会工程学攻击**
  - 钓鱼攻击
  - 伪装攻击

### 1.4 网络安全防护措施

主要的防护措施包括：

1. **技术防护**
   - 防火墙技术
   - 入侵检测系统
   - 数据加密技术

2. **管理防护**
   - 安全策略制定
   - 用户权限管理
   - 安全审计

3. **物理防护**
   - 机房安全
   - 设备保护
   - 环境监控

## 重要考点

- 网络安全的三大目标：机密性、完整性、可用性
- 常见网络攻击类型及其特点
- 网络安全防护体系的构建
- 加密技术的基本原理和应用
